2. HOW AI AGENTS WORK IN THIS PROJECT

WHAT IS AN AI AGENT?

An AI agent is a software program that:
• Perceives its environment (emails, meetings, user responses)
• Makes intelligent decisions based on data
• Takes actions automatically (sends emails, schedules meetings)
• Learns from interactions to improve over time

The KFSHRC Meeting Bot is an AI Agent because it:
• PERCEIVES: Reads incoming meeting requests and email responses
• THINKS: Analyzes all proposed times and counts votes
• DECIDES: Selects the best meeting time based on consensus
• ACTS: Sends confirmations, creates Outlook meetings, generates links

WHAT MODEL DID WE CHOOSE AND WHY?

We used Claude Sonnet (AI Foundation Model) for this project because:

Claude Sonnet Capabilities:
• Fast and efficient processing (ideal for real-time email handling)
• Strong language understanding (interprets emails naturally)
• Reliable decision-making (selects best meeting times accurately)
• Cost-effective (processes many requests without high overhead)

Why Claude for Meeting Scheduling?
• Understands natural language in emails (parses requests correctly)
• Logical reasoning (counts votes, finds consensus)
• Generates professional responses (creates quality confirmation emails)
• Handles complexity (manages multiple attendees and time zones)


WHAT IS A FOUNDATION AI MODEL?

A Foundation Model is a large language model trained on massive amounts of text data. It can:
• Understand human language (written requests, responses)
• Generate human-like responses (write professional emails)
• Reason logically (analyze data, make decisions)
• Adapt to different tasks (scheduling, responding, formatting)

Claude is a Foundation Model because it:
• Was trained on billions of words
• Can understand context and nuance
• Can perform many different tasks
• Can be guided by instructions (prompts)

Foundation models are the foundation for AI agents - the agent uses the model's language understanding to interpret emails and generate responses.

7. TROUBLESHOOTING

PROBLEM: Bot doesn't recognize my meeting request

SOLUTION:
1. Check subject line contains "meeting bot"
2. Make sure format is exactly:
   - Attendees: email1@domain, email2@domain
   - Topic: Meeting Title
   - Duration: number of minutes
3. Subject example: "meeting bot - My Meeting Title"


PROBLEM: I didn't receive a survey email

SOLUTION:
1. Check spam/junk folder
2. Check if you're blacklisted (ask administrator)
3. Make sure bot is running
4. Wait up to 1 minute for email to arrive


PROBLEM: My reply wasn't detected

SOLUTION:
1. Reply to bot's email (not forward)
2. Keep subject line with (ID: ...)
3. Format times exactly: DD-MM-YYYY HH:MM
4. One time per line
5. Don't include other text with times


PROBLEM: Classification popup appears when sending

SOLUTION:
1. Click OK to dismiss (auto-click should handle)
2. Email will go through after popup
3. If repeated, upgrade pywinauto:
   python -m pip install pywinauto --upgrade


PROBLEM: Time zone issues

SOLUTION:
1. Always use local Saudi Arabia time (Arabia Standard Time)
2. Example: 10-08-2026 14:00 (2:00 PM Saudi time)
3. Bot uses your system time zone


8. BEST PRACTICES

DO:

✓ Be clear in meeting title
  "meeting bot - Q3 Budget Review" (GOOD)
  "meeting bot - stuff" (VAGUE)

✓ Give reasonable deadline
  "Deadline: 10-08-2026 17:00" (GOOD)
  5 minutes is too short (BAD)

✓ Invite right people
  Only people who actually need to attend
  Each extra person slows consensus

✓ Propose realistic times
  Within work hours (9 AM - 5 PM)
  Near-future dates only

✓ Reply promptly
  Don't delay responses
  Earlier = faster scheduling


DON'T:

✗ Forget "meeting bot" in subject
  Bot won't recognize it!

✗ Use weird time formats
  WRONG: 10/08/26 2:30 PM
  RIGHT: 10-08-2026 14:30

✗ Reply to old emails
  Always reply to latest survey

✗ Propose past dates
  Use future dates only

✗ Invite too many people
  More people = harder consensus

✗ Use invalid email formats
  Check for typos!
